# DevPractice Hub
DevPractice Hub is a personal web development learning dashboard built using HTML, CSS and JavaScript.
## Features
- HTML, CSS and JavaScript learning cards
- Learning progress tracker
- Interactive web development quiz
- Task management system
- Save learning notes
- LocalStorage functionality
- Responsive design for mobile and desktop
- ## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage
- ## Project Structure
DevPractice-Hub/
- index.html
- style.css
- script.js
- README.md
- ## Purpose
The purpose of this project is to revise and improve my web development concepts, practice JavaScript, and strengthen my frontend development skills.
